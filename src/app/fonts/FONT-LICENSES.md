# Web Font Sources

This project self-hosts the production web fonts used by the Opendex interface.

## Space Grotesk

- File: `SpaceGrotesk-latin.woff2`
- Role: Primary brand, heading, body, navigation and UI font.
- Source: Google Fonts CSS API, `Space Grotesk`, latin subset.
- License: SIL Open Font License.

## Geist Mono

- File: `GeistMono-latin.woff2`
- Role: Technical labels, metrics, code, terminal-style UI and compact system text.
- Source: Google Fonts CSS API, `Geist Mono`, latin subset.
- License: SIL Open Font License.

Only the Latin web subsets are included to keep font payload small while covering Spanish and English product copy.
